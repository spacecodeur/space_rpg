# Project-Specific Instructions for Claude

## Ratatui Documentation Usage

This project uses ratatui version 0.29. When working on any task related to ratatui development, please follow these steps:

1. **First, consult the official ratatui guide** located in `docs/ratatui/guide/`
   - This contains comprehensive documentation about concepts, patterns, and best practices
   - Key sections include:
     - Application patterns and architecture
     - Event handling
     - Layout system
     - Widget usage
     - Styling and theming

2. **Then, reference the official ratatui API documentation** located in `docs/ratatui/code/`
   - This contains the complete API reference with examples
   - Use this to understand specific structs, traits, and functions
   - Check implementation details and method signatures

These local documentation resources should be your primary reference when implementing ratatui features to ensure compatibility with version 0.29 and adherence to current best practices.
