1//! # Mutable Widget Pattern
2//!
3//! This example demonstrates implementing the `Widget` trait on a mutable reference (`&mut T`)
4//! to allow direct state mutation during rendering. This is one of the simplest approaches for
5//! widgets that need to maintain their own state.
6//!
7//! This example runs with the Ratatui library code in the branch that you are currently
8//! reading. See the [`latest`] branch for the code which works with the most recent Ratatui
9//! release.
10//!
11//! [`latest`]: https://github.com/ratatui/ratatui/tree/latest
12//!
13//! ## When to Use This Pattern
14//!
15//! - You have self-contained widgets with their own state
16//! - You prefer an object-oriented approach to widget design
17//! - Your widget's state is simple and doesn't need complex sharing
18//! - You want to encapsulate state within the widget itself
19//!
20//! ## Trade-offs
21//!
22//! **Pros:**
23//! - Simple and intuitive - state is encapsulated within the widget
24//! - Familiar pattern for developers coming from OOP backgrounds
25//! - Direct state access without external state management
26//! - Works well with Rust's ownership system for simple cases
27//!
28//! **Cons:**
29//! - Can lead to borrowing challenges in complex scenarios
30//! - Requires mutable access to the widget, which may not always be available
31//! - Less flexible than `StatefulWidget` for shared or complex state patterns
32//! - May require careful lifetime management in nested scenarios
33//!
34//! ## Example Usage
35//!
36//! The widget implements `Widget` for `&mut Self`, allowing it to mutate its internal state
37//! during the render call. Each render increments a counter, demonstrating state mutation.
38
39use ratatui::buffer::Buffer;
40use ratatui::layout::Rect;
41use ratatui::widgets::Widget;
42use ratatui_state_examples::is_exit_key_pressed;
43
44/// Demonstrates the mutable widget pattern for mutable state management.
45///
46/// Creates a counter widget using `Widget` for `&mut Self` and runs the application loop,
47/// updating the counter on each render cycle until the user exits.
48fn main() -> color_eyre::Result<()> {
49    color_eyre::install()?;
50    ratatui::run(|terminal| {
51        let mut counter = Counter::default();
52        loop {
53            terminal.draw(|frame| frame.render_widget(&mut counter, frame.area()))?;
54            if is_exit_key_pressed()? {
55                break Ok(());
56            }
57        }
58    })
59}
60
61/// A counter widget that maintains its own state and increments on each render.
62///
63/// Demonstrates the mutable widget pattern by implementing `Widget` for `&mut Self`.
64#[derive(Default)]
65struct Counter {
66    counter: usize,
67}
68
69impl Widget for &mut Counter {
70    fn render(self, area: Rect, buf: &mut Buffer) {
71        self.counter += 1;
72        format!("Counter: {counter}", counter = self.counter).render(area, buf);
73    }
74}
