1//! # Function-Based Pattern with Immutable State
2//!
3//! This example demonstrates using standalone functions for rendering widgets with immutable
4//! state. This pattern keeps state management completely separate from widget rendering logic,
5//! making it easy to test and reason about.
6//!
7//! This example runs with the Ratatui library code in the branch that you are currently
8//! reading. See the [`latest`] branch for the code which works with the most recent Ratatui
9//! release.
10//!
11//! [`latest`]: https://github.com/ratatui/ratatui/tree/latest
12//!
13//! ## When to Use This Pattern
14//!
15//! - You prefer functional programming approaches
16//! - Your rendering logic is simple and doesn't need complex widget hierarchies
17//! - You want clear separation between state and rendering
18//! - You're building simple UIs or prototyping quickly
19//!
20//! ## Trade-offs
21//!
22//! **Pros:**
23//! - Simple - easy to understand and test
24//! - Pure functions - no side effects in rendering
25//! - Flexible - can easily compose multiple render functions
26//! - Clear separation - state management is completely separate from rendering
27//!
28//! **Cons:**
29//! - Limited - doesn't integrate with Ratatui's widget ecosystem
30//! - Verbose - requires passing state explicitly to every function
31//! - No reuse - can't be used with existing Ratatui widget infrastructure
32//!
33//! ## Example Usage
34//!
35//! The function takes immutable references to both the frame and state, ensuring that
36//! rendering is a pure operation that doesn't modify state.
37
38use ratatui::Frame;
39use ratatui::layout::Rect;
40use ratatui_state_examples::is_exit_key_pressed;
41
42/// Demonstrates the function-based pattern for immutable state rendering.
43///
44/// Creates a counter state and renders it using a pure function, incrementing the counter
45/// in the application loop rather than during rendering.
46fn main() -> color_eyre::Result<()> {
47    color_eyre::install()?;
48    ratatui::run(|terminal| {
49        let mut counter_state = Counter::default();
50        loop {
51            terminal.draw(|frame| render_counter(frame, frame.area(), &counter_state))?;
52            // State updates happen outside of rendering
53            counter_state.increment();
54            if is_exit_key_pressed()? {
55                break Ok(());
56            }
57        }
58    })
59}
60
61/// State for the counter.
62///
63/// This state is managed externally and passed to render functions as an immutable reference.
64#[derive(Default)]
65struct Counter {
66    count: usize,
67}
68
69impl Counter {
70    /// Increment the counter value.
71    fn increment(&mut self) {
72        self.count += 1;
73    }
74}
75
76/// Pure render function that displays the counter state.
77///
78/// Takes immutable references to ensure rendering has no side effects on state.
79/// This function can be easily tested and composed with other render functions.
80fn render_counter(frame: &mut Frame, area: Rect, state: &Counter) {
81    frame.render_widget(format!("Counter: {}", state.count), area);
82}
