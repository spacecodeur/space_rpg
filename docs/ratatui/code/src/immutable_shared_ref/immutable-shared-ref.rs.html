1//! # Shared Reference Pattern with Immutable State
2//!
3//! This example demonstrates implementing the `Widget` trait on a shared reference (`&Widget`)
4//! with immutable state. This is the recommended pattern for most widgets in modern Ratatui
5//! applications, as it allows widgets to be reused without being consumed.
6//!
7//! This example runs with the Ratatui library code in the branch that you are currently
8//! reading. See the [`latest`] branch for the code which works with the most recent Ratatui
9//! release.
10//!
11//! [`latest`]: https://github.com/ratatui/ratatui/tree/latest
12//!
13//! ## When to Use This Pattern
14//!
15//! - You want to reuse widgets across multiple renders
16//! - Your widget doesn't need to modify its state during rendering
17//! - You want the benefits of Ratatui's widget ecosystem
18//! - You're building modern, efficient Ratatui applications
19//!
20//! ## Trade-offs
21//!
22//! **Pros:**
23//! - Reusable - widget can be rendered multiple times without reconstruction
24//! - Efficient - no cloning or reconstruction needed
25//! - Standard - integrates with Ratatui's widget ecosystem
26//! - Modern - follows current Ratatui best practices
27//!
28//! **Cons:**
29//! - Immutable - cannot modify widget state during rendering
30//! - External state - requires external state management for dynamic behavior
31//!
32//! ## Example Usage
33//!
34//! The widget implements `Widget for &Counter`, allowing it to be rendered by reference
35//! while keeping its internal data immutable during rendering.
36
37use ratatui::buffer::Buffer;
38use ratatui::layout::Rect;
39use ratatui::widgets::Widget;
40use ratatui_state_examples::is_exit_key_pressed;
41
42/// Demonstrates the shared reference pattern for immutable widget rendering.
43///
44/// Creates a counter widget that can be rendered multiple times by reference,
45/// with state updates happening outside the widget's render method.
46fn main() -> color_eyre::Result<()> {
47    color_eyre::install()?;
48    ratatui::run(|terminal| {
49        let mut counter = Counter::new();
50        loop {
51            terminal.draw(|frame| {
52                // Widget is rendered by reference, can be reused
53                frame.render_widget(&counter, frame.area());
54            })?;
55            // State updates happen outside of rendering
56            counter.increment();
57            if is_exit_key_pressed()? {
58                break Ok(());
59            }
60        }
61    })
62}
63
64/// A counter widget with immutable rendering behavior.
65///
66/// Implements `Widget` on a shared reference, allowing the widget to be rendered
67/// multiple times without being consumed while keeping its data immutable during rendering.
68struct Counter {
69    count: usize,
70}
71
72impl Counter {
73    /// Create a new counter.
74    fn new() -> Self {
75        Self { count: 0 }
76    }
77
78    /// Increment the counter value.
79    ///
80    /// This method modifies the counter's state outside of the rendering process,
81    /// maintaining the separation between state updates and rendering.
82    fn increment(&mut self) {
83        self.count += 1;
84    }
85}
86
87impl Widget for &Counter {
88    fn render(self, area: Rect, buf: &mut Buffer) {
89        // Rendering is immutable - no state changes occur here
90        format!("Counter: {}", self.count).render(area, buf);
91    }
92}
