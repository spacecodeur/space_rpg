1//! # StatefulWidget Pattern (Recommended)
2//!
3//! This example demonstrates the `StatefulWidget` trait, which is the recommended approach for
4//! handling mutable state in Ratatui applications. This pattern separates the widget's rendering
5//! logic from its state, making it more flexible and reusable.
6//!
7//! This example runs with the Ratatui library code in the branch that you are currently
8//! reading. See the [`latest`] branch for the code which works with the most recent Ratatui
9//! release.
10//!
11//! [`latest`]: https://github.com/ratatui/ratatui/tree/latest
12//!
13//! ## When to Use This Pattern
14//!
15//! - Most Ratatui applications (this is the recommended default)
16//! - When building reusable widget libraries
17//! - When you need clean separation between rendering logic and state
18//! - When multiple widgets might share similar state structures
19//! - When you want to follow idiomatic Ratatui patterns
20//!
21//! ## Trade-offs
22//!
23//! **Pros:**
24//! - Clean separation of concerns between widget and state
25//! - Reusable - the same widget can work with different state instances
26//! - Testable - state and rendering logic can be tested independently
27//! - Composable - works well with complex application architectures
28//! - Idiomatic - follows Ratatui's recommended patterns
29//!
30//! **Cons:**
31//! - Slightly more verbose than direct mutation patterns
32//! - Requires understanding of the `StatefulWidget` trait
33//! - State must be managed externally
34//!
35//! ## Example Usage
36//!
37//! The widget defines its rendering behavior through `StatefulWidget`, while the state is
38//! managed separately. This allows the same widget to be used with different state instances
39//! and makes testing easier.
40
41use ratatui::buffer::Buffer;
42use ratatui::layout::Rect;
43use ratatui::widgets::{StatefulWidget, Widget};
44use ratatui_state_examples::is_exit_key_pressed;
45
46/// Demonstrates the StatefulWidget pattern for mutable state management.
47///
48/// Creates a counter widget using `StatefulWidget` and runs the application loop,
49/// updating the counter on each render cycle until the user exits.
50fn main() -> color_eyre::Result<()> {
51    color_eyre::install()?;
52    ratatui::run(|terminal| {
53        let mut counter = 0;
54        loop {
55            terminal.draw(|frame| {
56                frame.render_stateful_widget(CounterWidget, frame.area(), &mut counter)
57            })?;
58            if is_exit_key_pressed()? {
59                break Ok(());
60            }
61        }
62    })
63}
64
65/// A counter widget that uses the StatefulWidget pattern for state management.
66///
67/// Demonstrates the separation of rendering logic from state, making the widget reusable
68/// with different state instances and easier to test.
69struct CounterWidget;
70
71impl StatefulWidget for CounterWidget {
72    type State = usize;
73
74    fn render(self, area: Rect, buf: &mut Buffer, state: &mut Self::State) {
75        *state += 1;
76        format!("Counter: {state}").render(area, buf);
77    }
78}
